# 物理検証ファースト (BPM ソルバーの変更ルール)

このリポジトリは数値物理ソルバーである。「ビルドが通る・落ちない」は
合格条件ではない。**数値が物理として正しいことを示して初めて完了**とする。

## 変更の種類ごとの必須検証

| 変更 | 必須検証 |
|---|---|
| 伝搬カーネル / 係数 (ax, ay, d, ADI, Stern, Pade) | `ctest` (解析解比較) + 該当する解析解との定量比較を新設 or 更新 |
| 励振・吸収体・屈折率構築 | 電力保存 (自由空間で P/P0 = 1)、既存サンプルの出力電力が変化しないこと |
| 入力キーワード追加 | 動作するサンプル .ofd を data/ に追加し、期待値をコメントで明記 |
| 出力 (HDF5) 変更 | tools/plot_ixz.py・post/postbpm.c・GUI が読めること (スキーマ互換) |

## 使える解析解 (検証の定番)

- 自由空間ガウシアン回折: w(z) = w0·sqrt(1+(z/zR)^2), zR = π·w0²·n/λ
- 均一吸収媒質: P(z)/P(0) = exp(-2·k0·n''·z)
- スラブ導波路 TE/TM: 分散方程式から neff・減衰定数 γ (半ベクトル検証)
- ステップインデックスファイバ LP モード: tests/test_modes.cpp の厳密解関数
- GI ファイバ自己集束ピッチ: Λ = 2π·a/sqrt(2Δ)
- チルトビーム変位: 近軸 z·sin θ / 厳密 z·tan θ (広角検証)

## 数値の読み方の注意

- 測定方法自体が誤差源になる (フィット窓依存など)。理論との差が出たら
  まず **メッシュ/ステップを半分にして収束方向を確認**し、離散化誤差
  (FD 分散込みの理論値) と実装バグを区別する。
- スナップショット断面はモード+放射の干渉で振動する。定常量は
  Ixz の z 平均や電力などの積分量で評価する。
- float の伝搬カーネルと double の wabpm で精度が違う。比較は同精度で。
